# R翻訳 / RTranslate

Safariで再生する英語ウェビナーを、日本語字幕と日本語音声で視聴するMacアプリとSafari Web Extensionです。Built with PLaMo.

## インストール（ソースのビルドは不要）

Apple Silicon（Mシリーズ）・macOS 26以降が対象です。

1. [インストーラ RTranslate-v0.4.8-macOS-arm64.pkg](https://github.com/haruxbt/RTranslate/releases/download/v0.4.8/RTranslate-v0.4.8-macOS-arm64.pkg) をダウンロードします。その他の版は[Releases](https://github.com/haruxbt/RTranslate/releases)で確認できます。

   <strong>注：個人開発版（未公証・仮署名）のため、初回はmacOSでこのインストーラを個別に許可する操作と、Safariの開発版拡張の許可が必要です。[スクリーンショット付きインストール手順](docs/INSTALL.md)を参照してください。</strong>

2. 詳細手順に沿ってインストールし、アプリケーションフォルダの「R翻訳」を起動します。初回はモデルのダウンロード完了を待ちます。
3. Safari設定でR翻訳を有効にし、動画を再生して拡張から「翻訳開始」を押します。

<strong>「Source code (zip)」「Source code (tar.gz)」は開発用で、インストール用ではありません。</strong> Xcode、Python、Homebrewの導入やソースからのビルドは不要です。

更新通知後も完成済みのPKGで更新します。ワンクリック自動更新は未実装です。モデル・履歴・設定は引き継ぎます。起動中のR翻訳へはインストーラが通常終了を要求し、終了できなければ更新を中止します。[アップデートの手順](docs/INSTALL.md#アップデートするとき)も確認してください。

旧名「Webinar Nihongo」からの更新では、同じアプリと確認できた旧版だけを復旧用に退避します。モデル・履歴・設定の保存場所は変わりません。

## v0.4.8の変更

- Safari拡張の「詳細設定」で **録画HLSを先読みして同期（試験）** を有効にしてから翻訳を始めます。対応する録画では動画より最大25秒先までの音声を取得し、訳ができた順に、動画時刻付きでタイムラインに表示します。最下部で実際の音声取得の先行時間と準備済みの音声数を確認できます。
- **動画に日本語字幕を表示（先読み同期）** を有効にすると、準備済みの日本語が動画上の字幕として動画の再生時刻に表示されます。日本語音声をミュートしても字幕は表示されます。翻訳が再生位置に間に合わなければ字幕も遅れます。読み上げる日本語が長い場合は音声に遅れが残ることがあります。
- 先読みの既定値はオフです。対応する録画HLSとVOICEVOXの組み合わせで使えます。ライブ配信や先読みに対応しない動画では、先読みをオフにして通常翻訳をお試しください。シーク後は移動先で翻訳を開始し直します。
- Safariの埋め込み動画フレームを検出して開始・停止する処理と、Safariを背面にしたときのHLS音声転送を見直しました。
- PLaMoの同梱環境を軽くし、Mac mini上でひとつ前の軽量化前の検証版に比べてアプリ本体を約138 MiB削減しました。設定の「モデル」でVOICEVOXの合成を標準の2スレッドから4に変更できます。
- 辞書はRSpeechと共通の「単語・読み方・アクセント」で編集できます。共通辞書の更新後に個人登録の追加候補を選んで共有できます。サポートから音声認識の誤りも報告できます。共有や報告はGitHubの投稿画面で内容を確認し、投稿を確定します。
- 音声認識にセキュリティ用語をヒントとして渡し、文脈に応じてSOC、SBOM、CBOMや「ゼロデイ」の認識・翻訳の表記を補正します。
- 「ページ」タブは **日本語に訳して読む** が既定です。表示中の本文をそのまま読むこともできます。翻訳と音声合成はこのMacで行い、ページの本文は履歴に保存しません。

Mac miniの合成英語による結合試験で、動画の時刻を進める前に訳文と日本語音声が準備され、指定時刻まで読み上げが始まらないことを確認しました。この版の実BrightTALKとMacBook Airでの同期精度・負荷は未測定です。

## v0.3.10の容量削減

不要なPythonの同梱ファイルを省き、VOICEVOXの実行ライブラリをモデルと同じ外部フォルダに1つだけ保存します。更新時は既存ファイルのハッシュを確認して再利用します。初回はVOICEVOX公式配布元から取得し、圧縮ファイルと取り出したライブラリを検証します。Homebrewの追加セットアップは不要です。

## v0.3.9の音声先読み

最大5文先まで日本語音声を順番に生成し、先読みWAVの保持量を24MiBまでに制限します。合成は同時に1件だけ行い、速度は再生時に適用して速度変更による再合成を避けます。文章の省略・要約はしません。未翻訳の文章は準備できず、合成が追いつかない場合には待ちが残ります。

Safariの音声転送は約8秒分まで一時的な詰まりを吸収します。順番・欠落チェックは維持し、長く詰まる場合は停止します。取得停止とデータ形式のエラーを分け、後続の要求が元の停止理由を上書きしないようにしました。更新後はウェビナーページを再読み込みしてください。

Miniの実VOICEVOX＋無音再生で同じ16文（短文2つの後に長文）を比較し、長文前の待ちは旧版2.73秒→新版1.29秒でした。最大5文を先読みし、先読みWAV保持はこの試験で約0.5MB。各1回の測定で、Airでの速度・実BrightTALKの停止解消は未確認です。非同期バッファ7項目、Core21項目、拡張48項目の独立試験も成功しました。

### 短文と読み上げ速度

短い英文は次の文とまとめて翻訳します。目安は24語で、無音4秒または待ち時間14秒で確定します。文章の意味と順序を保ち、同じ長さへの強制分割はしません。自動加速は待ち件数ではなく推定読み上げ残量で判断し、15秒以上で最大×1.5、7.5秒以下で通常速度へ戻します。×1.75・×2は手動指定です。速度は文の切り替わり時に変えます。新しい区切りのAir・実ウェビナー検証は未実施です。

## v0.3.8のメニューバー調整

メニューバーのアイコンを専用の18ポイントの図形描画へ変更し、小さく細くしました。ブラウザ用PNGの縮小をやめ、表示倍率に合わせて描画します。Safari側のアイコンと翻訳・音声の処理は変更していません。Miniでビルドと通常/Retina相当の描画を確認しました。Airでの新版の見え方は未確認です。

## v0.3.7のISC2開始対策

ISC2のプレーヤーのように部品の内側（open Shadow DOM）にある動画も探索するよう修正しました。サイトへの権限やCORS・DRMの制約は引き続き適用されます。開始に失敗した理由は定期更新で消さず、再試行・停止まで表示します。

Safariの状態保存がエラーになる場合も初期化を止めず、セッションは一時的にメモリ上で管理します。設定・履歴はMacアプリに保持し、Safariのデータベースは削除しません。この場合、拡張の再起動後は翻訳を開始し直してください。独立テスト46項目成功。Miniで実ISC2ページから開始し、日本語訳4件のブラウザ内表示と読み上げ中の表示を確認しました。利用者からAirでも正常動作し、稼働中の0.3.6から更新できたとの報告を受けています。この更新ではSafariの再許可・拡張の再指定も不要でした。

## v0.3.6の設定画面と更新手順

設定を「概要・辞書・スライド・モデル・履歴・サポート」の6ページに整理しました。ウィンドウは一定の幅で、Safariの歯車から目的の管理ページを開けます。日常の音量・速度・翻訳方式は拡張の詳細設定で変更し、Macアプリと共有します。辞書は行ごとに追加・編集でき、モデルの保存量や履歴の保持ルールも確認できます。

インストーラがアプリへ通常終了を要求し、終了できなければ更新を中止します。自動で強制終了はしません。新アプリは終了時に確定した履歴を保存します。Mac miniで全6ページの実画面、通常終了、共有設定、Core20・拡張40・資産3・移行5項目の確認を行いました。Airでの実インストール、管理者権限でのpkg全体の実行、新版Safari吹き出しの実操作は未確認です。

## v0.3.5のブラウザ内タイムライン対策

拡張内の音声取得状態に依存せず、表示中ページのURLをMac側の取得対象と照合して訳文を読み出す経路を追加しました。別ページの訳文は返しません。未接続・音声待ち・認識中・エラーを空表示の代わりに案内します。Mac miniで合成音声から3件の訳文取得、別ページには0件、拡張38テストを確認。Airで報告された症状の再現と解消確認は未実施です。

更新する場合はSafariとR翻訳を終了してインストールし、Safariで試験用未署名許可と拡張を有効にしてから、ウェビナーページを再読み込みして拡張から翻訳開始してください。

## 機能と状態

- メニューバーのMacアプリが英語音声認識・PLaMo翻訳・VOICEVOX読み上げを担当します。拡張単体では動きません。
- Mac版はScreenCaptureKit、Safari拡張はページ内メディア/HLSから取得します。サイトや保護コンテンツによって取得できないことがあります。
- 日本語タイムライン、読み上げ位置の強調、速度/音量調整、辞書、スライドOCRを備えます。
- 音声・映像は常時保存せず、確定原文と日本語訳をローカルで3か月保存します。取得開始ごとに表示タイムラインを分けます。
- LLM重み・音声モデルはアプリ外のApplication Support/RTranslate/Assetsへ取得します。
- 音声入力は現在英語に固定。動画URL/再生時刻と結び付けた過去訳の再利用と、Chrome接続は未実装です。
- Mac mini M1で開発。MacBook Air M2 8GBでの性能は未検証です。

## 開発

macOS 26以降・Apple Silicon・対応するSwift SDK/Xcodeが必要です。

```sh
swift build --product WebinarNihongo
swift run WebinarCoreChecks
swift run SpeechBufferChecks
node --experimental-vm-modules --test Tests/Extension/*.test.mjs
python3 Tests/Integration/asset_store_checks.py
```

上記はネイティブソースのビルドと独立テストです。Safari拡張のXcodeプロジェクトは `SafariExtension/Xcode` にあります。

<strong>公開ソースにはモデル重み、Python/MLX/VOICEVOX/ONNXの実行バイナリ、個人用の完成アプリを含めません。</strong> 完成アプリのパッケージ化には、対応するランタイムと各ライセンスを揃えたベースアプリが別途必要です。`scripts/build_safari_preview.sh` はその準備済みベースを要求し、ソースを取得しただけではインストーラを作れません。公開ソースから実行環境を一式構築する手順は整備中です。

未署名のSafari開発版は本人がSafariの試験用許可を有効にする必要があります。Developer ID署名・公証済みの一般配布版はまだありません。
